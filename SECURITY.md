# Security Policy

## Supported versions

This repository currently contains prompt architecture and documentation. Security fixes are applied to the latest version on the default branch.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue. Report them privately to the repository owner through GitHub, including:

- A clear description of the issue
- Steps to reproduce it
- Potential impact
- Any suggested mitigation

Please avoid including secrets, personal data, or real candidate information in reports. You should receive an acknowledgement as soon as practical. Issues will be investigated and addressed based on severity and available project scope.
