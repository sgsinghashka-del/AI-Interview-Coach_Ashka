# Contributing to AI Interview Coach

Thank you for your interest in improving AI Interview Coach.

## Before you start

- Read the [README](README.md) and review the existing prompt architecture.
- Open an issue before making a large change so the approach can be discussed.
- Keep prompt behavior explicit, testable, and aligned with the project's evaluation-first goals.

## Making a change

1. Create a focused branch from `main`.
2. Make one logical change per pull request.
3. Update the README or prompt documentation when behavior or structure changes.
4. Check that links, Markdown formatting, and diagrams render correctly.
5. Open a pull request using the repository template.

## Prompt contributions

When adding or changing prompts, explain:

- The prompt's responsibility and intended input/output
- The persona, constraints, or evaluation criteria it affects
- How the change reduces ambiguity, drift, bias, or inconsistent scoring
- At least one representative example where practical

Do not include real candidates' personally identifiable or confidential interview data.

## Pull requests

Pull requests should include a concise summary, the motivation for the change, and any limitations or follow-up work. Maintainers may request revisions before merging.
